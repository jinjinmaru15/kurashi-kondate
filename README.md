# くらしの献立帖

ふたりで使う、献立・レシピ・買い物リスト・勤務と予定の手帳です。iPhone の Safari からホーム画面に追加して使うことを想定しています。

- **カレンダー**：月／週表示。勤務（日勤・準夜勤・深夜勤・休み・その他）と予定（外出・買い物・家事・自由入力）を色分けし、ふたりの予定を1つのカレンダーで表示します。自分だけの予定（🔒）も登録できます。
- **献立**：主菜・副菜・汁物・その他を何品でも登録できます。料理名を入力するとレシピの候補が出て、選ぶとレシピと紐づきます。前日・翌日へのコピーと、過去の献立の検索もできます。
- **レシピ**：写真、材料、何人分か、作り方、参考URL（Instagram・TikTok・YouTube など）、メモ、お気に入り、作った記録を保存できます。URLだけの簡易登録にも対応しています。
- **買い物リスト**：カテゴリー別に表示し、購入済みは下にまとめます。期間を指定すると、献立に使うレシピの材料を集めて追加できます（同じ材料・同じ単位は合算）。どちらかがチェックすると、相手の画面にもすぐ反映されます。

## しくみ

| 役割 | 使っているもの |
|---|---|
| 画面 | このリポジトリの静的ファイル（GitHub Pages で公開） |
| ログイン | Supabase Auth（メールアドレスとパスワード） |
| データ | Supabase の Postgres。アクセス制御は Row Level Security |
| 相手の変更をすぐ表示 | Supabase Realtime |

データはすべて「スペース」に属します。

- **じぶん**：ログインすると自動で作られる、自分だけのスペース
- **ふたり**：招待コードで相手が参加するスペース

スペースのメンバー以外は、そのスペースのデータを読むことも書くこともできません。この制限は Supabase のサーバー側で強制されます（`supabase/schema.sql`）。じぶんのスペースのデータが勝手に共有されることはなく、共有したいレシピだけを「ふたりのスペースにコピー」で移せます。

## 最初のセットアップ（1回だけ）

### 1. Supabase

1. [supabase.com](https://supabase.com) で無料のプロジェクトを作ります（リージョンは Tokyo がおすすめです）。
2. **SQL Editor** を開き、`supabase/schema.sql` の中身をすべて貼り付けて **Run** を押します。（kurashi-kondate プロジェクトには適用済みです。「ふたりのスペースから抜ける」「メンバーを外す」を使うときだけ、ファイル末尾の「オプション」部分を実行してください）
3. **Authentication → URL Configuration** を開き、次のように設定します。
   - **Site URL**：`https://jinjinmaru15.github.io/kurashi-kondate/`
   - **Redirect URLs**：同じURLを追加します
   - これを設定しないと、確認メールのリンクが正しいページに戻りません。
4. **Project Settings → API** の `Project URL` と `anon public` キーを `config.js` に入れます。（設定済みです）

### 2. GitHub Pages

1. リポジトリの **Settings → Pages** で、Source を **GitHub Actions** にします。
2. `main` に push すると、`.github/workflows/pages.yml` が動いて公開されます。

### 3. ふたりで使い始める

1. 自分がアプリを開いて「はじめて使う」から登録し、確認メールのリンクを開いてからログインします。
2. **設定 → ふたりのスペースを作る** を押すと、招待コードが出ます。「LINEなどで送る」で相手に送ります。
3. 相手は届いたリンクを開いて登録・ログインします。招待コードが自動で入るので「参加する」を押します。
4. ふたりとも登録できたら、Supabase の **Authentication → Providers → Email** で「Allow new users to sign up」をオフにしておくと、ほかの人が登録できなくなって安心です。

### 4. ホーム画面に追加

Safari でアプリを開き、共有ボタン →「ホーム画面に追加」を選びます。

## 以前の版（claude.ai 版）からの引っ越し

claude.ai 版の **設定 → バックアップを書き出す** で保存した JSON を、このアプリの **設定 → バックアップを読み込む** で読み込めます。読み込み先は、そのとき使っているスペース（ふたり／じぶん）です。

## ファイル

```
index.html            画面の骨組み
styles.css            デザイン
app.js                アプリ本体
config.js             Supabase の接続先
sw.js                 オフライン表示用（Service Worker）
manifest.webmanifest  ホーム画面アプリの設定
icons/                アイコン
supabase/schema.sql   データベースとアクセス制御の定義
```

## 注意

- `config.js` に入れるのは **anon（public）キー** だけです。`service_role` キーは絶対に入れないでください。
- オフラインのときは、最後に読み込んだ内容を表示します。オフライン中の変更は保存されません。
